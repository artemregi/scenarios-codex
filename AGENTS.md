# Система сценариев – инструкция для Codex

Ты помогаешь ученику курса, он не программист. Отвечай по-русски, коротко, простыми словами. Команды запускай сам,
у ученика спрашивай только ключи, логины и выбор.

## Что это

Каждую ночь система смотрит блогеров из `bloggers.txt`, находит залёты (просмотры ≥ 2 × медиана автора),
расшифровывает их и пишет сценарии под ученика по `knowledge/passport.md` и `knowledge/style.md`. Сценарии уходят в
Telegram, все идеи – на сайте http://localhost:8777.

| команда | что делает |
|---|---|
| `python3 doctor.py [--full]` | проверка всего, таблица ✅ / ❌ |
| `python3 passport.py` | паспорт и стиль из `anketa.md` |
| `python3 discover.py [--add N]` | поиск новых блогеров ниши |
| `python3 collect.py [ник]` | сбор залётов (паузы между блогерами до минуты – это нормально) |
| `python3 transcribe.py` | расшифровка залётов |
| `python3 write.py [N] [--id код]` | оценка идей и сценарии, отправка в Telegram |
| `python3 bank.py` | сайт банка идей, запускать в фоне |
| `python3 run.py` | всё по очереди (так работает ночной запуск) |
| `python3 schedule.py on / off / status` | ночной запуск в 03:00 |
| `python3 login.py` | вход в отдельный Instagram в Chrome |

На Windows вместо `python3` – `python` (или `py -3.12`). Скрипты сами переключаются на окружение `.venv`.
Данные – `data/reels.db`, сценарии – `scripts/`, журналы – `logs/`.

## Правила

- Значения ключей из `.env` никогда не выводи на экран и никуда не копируй.
- Не трогай `.env`, `anketa.md`, `knowledge/`, `bloggers.txt`, `ig_profile/`, `data/` без просьбы ученика.
- Долгие команды (`discover.py`, `collect.py`, `transcribe.py`, `write.py`) не прерывай: они идут 3–15 минут.
  Ставь таймаут команды не меньше 20 минут.
- `bank.py` запускай в фоне, чтобы сайт продолжал работать после ответа.
- Скрипты сами вызывают модель через `codex exec` (`lib/llm.py`), отдельный ключ OpenAI не нужен.
- Если `python3` нет или он старше 3.10 – запускай скрипты через `.venv/bin/python` (Windows – `.venv\Scripts\python.exe`).
- Сеть, Chrome и запись вне папки нужны системе: если команда падает с ошибкой доступа или сети, скажи ученику
  выбрать **Full access** в переключателе разрешений под строкой ввода и повтори команду.
- Если `doctor.py` пишет «Codex не вошёл в аккаунт» – запусти `codex login` сам, скажи ученику войти в браузере тем же
  аккаунтом ChatGPT и жди. Если `codex` не находится – путь есть в `lib/llm.py` (`find_codex`).
- Если кончился лимит Codex – скажи, когда он сбросится (это видно на chatgpt.com/codex/settings/usage), и не запускай
  `write.py` до сброса.
- Правила сценариев – `knowledge/rules.md` и `knowledge/check.md`. Правишь сценарий – сверяйся с ними и со стилем.
